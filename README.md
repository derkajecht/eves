# EVES

My first attempt at creating a neural network. Currently studying a Machine Learning module at
uni and wanted to see if I could build something from scratch without using ML libraries.

The math side of this still baffles me, specifically the delta's in the loss function.
But overall, this has been very interesting to read about and implement.

I've used the CIFAR-10 dataset and currently am getting around 1.6 loss with 46% accuracy at it's best.
I want to test out different architecture, maybe using transformers instead of the typical dense
layers and try out some other optimisations to help push this to 60% accuracy.
